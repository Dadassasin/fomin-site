# Персональный сайт Фомина Тимофея Владимировича

Статический персональный сайт магистранта Кубанского государственного университета. Резюме доступно на русском и английском языках.

## Запуск

Откройте `index.html` в браузере. Он переводит на `index.htm`. Установка зависимостей и сборка не нужны.

## Структура

- `index.htm`, `indexe.htm`: резюме RU и EN.
- `bio/`, `diss/`, `library/`, `links/`, `ind/`: разделы сайта. Сейчас их содержимое обозначено словом «дописать».
- `css/master_style.css`: общие стили.
- `assets/`: локальная эмблема и скрипт декоративной анимации.
- `fomin.htm`, `fomin.txt`: академические сведения.
- `resume_hard.txt`, `resume_soft.txt`: списки навыков.

## GitHub Pages

Репозиторий подготовлен для публикации из ветки `main`, папки `/ (root)`. GitHub Pages отдельно не настроен.
